# Documentation Update Rule for AI Agents

## Mandatory Requirement
After implementing any new feature, bug fix, dependency update, or UI change in this repository, the agent MUST read and update the corresponding text files inside the `doc/` folder.

## Formatting Constraints for doc/ Files
1. **No Markdown Headers:** Do NOT use `#`, `##`, or `###`. Use plain text uppercase section headers (e.g. `SECTION 1: SYSTEM OVERVIEW`).
2. **No Bullet Points:** Do NOT use `-`, `*`, or `+` bullet lists. Use structured paragraphs and numbered sentences.
3. **No Asterisks:** Do NOT use `*` or `**` for bold or italic styling.
4. **No AI Conversational Filler:** Write clean, formal, academic documentation suitable for a Human-Computer Interaction (HCI) thesis.
